Project and design basis

Define the project, the reporting basis and the tunnel cross-section; everything else builds on these. The usual path is: start from an example or a saved project, check the ground zones and choose the machine (Steps 2 and 3), read the carbon results and warnings (Step 6), search for a lower-carbon lining (Step 5), and export the model and the figures (Step 8).

Figures

Publication figures drawn by the engine from the current project (print style, Latin Modern Sans, colour-blind-checked palette): the same charts as on screen, for reports and papers. The route figures need ground zones; the zone-by-zone optimisation and the Pareto set run the optimiser (lining 0.30 to 0.50 m, C40 to C65, lining at the face, required FoS of the project).
