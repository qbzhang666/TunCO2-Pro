## Other files in the repository

- `integrations/tunco2_to_blender.py` runs inside Blender (GPL) and is licensed GPL-3.0-or-later. It exchanges data
  with TunCO2 Pro by files only; TunCO2 Pro does not import or link Blender.
- `web/assets/tbm/*.glb`: generic TBM-type models (MIT, as the rest of the project).
- `data/examples/`: synthetic example corridors generated by `tools/make_example_corridors.py` (MIT); no real
  project data.
- Leaflet 1.9.4 (BSD-2-Clause), vendored in `web/vendor/leaflet/`. Basemap tiles © OpenStreetMap contributors
  (ODbL), loaded online only.
- Optional build tools only (not runtime): rhino3dm (MIT), fast-simplification (MIT), mapbox-earcut (ISC).

## Latin Modern Sans (data/fonts)

The figure module ships Latin Modern Sans 10 (regular, bold, oblique) converted to TrueType, so that
exported figures use the same typeface as Computer Modern documents. Latin Modern is by B. Jackowski and
J. M. Nowacki (GUST e-foundry), released under the GUST Font License (GFL), which permits redistribution
and embedding; see https://www.gust.org.pl/projects/e-foundry/latin-modern.
